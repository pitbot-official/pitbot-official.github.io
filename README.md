# PITBOT 공식 홈페이지

**Your trainer, always on.**
누구나 언제든 자신에게 맞는 코칭을 경험할 수 있는 피지컬 AI 피트니스 플랫폼, PITBOT의 공식 홈페이지입니다.

🔗 https://pitbot-official.github.io

## PITBOT
| 구성 | 설명 |
| --- | --- |
| **PIT** | 이용자를 추적하며 실시간 자세 분석, 근육 시각화, 데이터 기록, 음성 피드백으로 코칭하는 AI 자율주행 로봇 |
| **POD + WEAR** | 모든 WEAR에 호환되는 코어 패치 POD이 근육 활성도를 측정하고 진동으로 타겟 부위를 짚어 주는 웨어러블 |
| **LOOP** | 루틴 탐색과 조정, 기록과 리포트, 식단 관리, 루틴 공유·판매를 잇는 전용 앱 |
| **LOOP Admin** | 공간·기구 자동 매핑, 실시간 관제, 데이터 기반 운영을 지원하는 운동 공간 운영 플랫폼 |
